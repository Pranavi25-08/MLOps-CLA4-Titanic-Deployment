# MLOps CLA 4 — Titanic Model Deployment

This project demonstrates model training, online inference, batch inference, simulated streaming inference, and FastAPI model serving using the Kaggle Titanic `train.csv` dataset.

## Files
- `train_model.py` — preprocesses data, trains/evaluates a Random Forest pipeline, saves `model.pkl`.
- `inference.py` — demonstrates online, batch, and streaming inference.
- `app.py` — FastAPI application with `/health` and `/predict`.
- `client.py` — example Python client for `/predict`.
- `model.pkl` — serialized trained pipeline (generated by training).
- `batch_predictions.csv` — 20 batch predictions (generated by inference).
- `requirements.txt` — dependencies.
- `screenshots/` — add screenshots of inference and API tests.
- `observations.md` — answers to the four assignment questions.

## Dataset
Download `train.csv` from the official Kaggle competition:
https://www.kaggle.com/competitions/titanic/data

Place `train.csv` in the project root. Do not upload Kaggle credentials or tokens.

## Run locally
```bash
pip install -r requirements.txt
python train_model.py
python inference.py
uvicorn app:app --reload
```
Open `http://127.0.0.1:8000/docs` to test the API. In another terminal, run `python client.py`.

## API examples
- `GET /health`
- `POST /predict` with JSON fields `Pclass`, `Sex`, `Age`, `SibSp`, `Parch`, `Fare`, `Embarked`.

A valid request returns a predicted class. Invalid field types or out-of-range values are rejected by Pydantic validation.
